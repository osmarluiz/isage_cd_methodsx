Change detection is one of the most widely used operations in remote
sensing. Comparing two co-registered images of the same place at
different dates shows where the surface changed, which is how urban
expansion~\cite{chen2020spatial}, post-disaster
damage~\cite{gupta2019xbd}, land-cover
transitions~\cite{yang2021asymmetric} and
deforestation~\cite{prodes,mapbiomas} are mapped. The supervised
methods behind these applications are built on pixel-level
labels~\cite{daudt2018fully,khelifi2020deep}, and producing those
labels is the main cost of a dataset. An analyst inspects the imagery,
decides the state of each pixel, and paints a dense mask. Change is
harder to label than a single image because the unit is a pair of
dates rather than one scene, and because the same scene can be
labeled against several reference dates, which multiplies the work.

Expert time is the binding constraint, and several families of methods
reduce it. Weak supervision replaces dense masks with image-level tags
or scribbles~\cite{lin2016scribblesup,hua2021semantic}, semi-supervised
methods pair a small labeled set with a large unlabeled
one~\cite{zhou2026decaf}, active learning chooses what the human
labels next~\cite{ren2021survey}, human-in-the-loop annotation lets
the model and the user take turns~\cite{amershi2014power,lenczner2022dial},
and point supervision replaces the mask with a few
clicks~\cite{Bearman2016}, including for change detection
specifically~\cite{fang2024point}. These reduce how many labels are
needed. They leave open where a label lives once a scene has more than
two dates, which is a question about the annotation record rather than
about the learning algorithm.

iSAGE~\cite{isage} (\emph{Iterative Sparse Annotation Guided by
Expert}) is a point-based, human-in-the-loop framework for
remote-sensing semantic segmentation in which an expert clicks on the
model's mistakes, an error-weighted loss amplifies the gradient at
each click, and the annotation record is itself the dataset. On
single-image benchmarks it recovered most of the quality of dense
labeling from far less than 1\% of the pixels. Its label file and
session layout assume one image per annotation, so there is nowhere to
record which two dates a click refers to. This article introduces
\textbf{iSAGE-CD}, which extends iSAGE to the bi-temporal case by
anchoring every label to a (before, after) pair, and documents the
tool and its session format through a working annotation session over
the Brazilian Amazon. A full quantitative evaluation is the subject of
a separate manuscript in preparation.
